# React Learning Journey 🚀

This repository is created to learn and practice **React** step by step.
It contains notes, examples, and small projects covering core React concepts.

## 📚 Topics Covered
- JSX
- Components
- Props & State
- Event Handling
- Conditional Rendering
- Lists & Keys
- Hooks (useState, useEffect)
- Basic Project Structure

## 🛠️ Tech Stack
- React
- JavaScript (ES6+)
- HTML & CSS
- Node.js & npm

## 🎯 Goal
The goal of this repository is to build a strong foundation in React and
gradually move towards building real-world applications.
